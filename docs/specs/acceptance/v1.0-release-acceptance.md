# v1.0 release acceptance specification

## Product

- A user can find a supported Indian instrument and understand exchange, timezone, source, delay, and timestamp.
- A supported BSE instrument page renders the official TradingView EOD widget across desktop and mobile states.
- TradingView attribution and the link remain visible.
- No application code, backend job, AI prompt, or analytics pipeline extracts TradingView widget data.
- A signal explains its timeframe, permitted evidence, uncertainty, methodology, and notice without relying on TradingView data.
- A news item has a source link, provenance, timestamp, rights state, and normalized summary.
- English and Hindi core flows are usable and reviewed.

## Safety and compliance

- Personalized trade requests are refused safely.
- Stale or missing data is visible.
- No public page exposes secrets, private data, unlicensed raw content, or extracted TradingView data.
- Legal, data, privacy, AI, security, and copyright reviews are recorded.

## Operations

- Provider outage, AI quota, backup restore, rollback, and alert paths are tested.
- Logs and metrics support investigation without storing unnecessary sensitive prompts.
- SEO controls prevent private, duplicate, stale, and unsupported pages from indexing.

## Release decision

Any failed compliance, data-rights, security, or privacy gate blocks public release even if the UI is complete.
